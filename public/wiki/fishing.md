# Рыбалка

![Торговая зона](/wiki-images/fishing.gif)

_Пример действия рыбалки_

Чтобы успешно поймать рыбу, нужно удерживать зелёную зону над движущейся рыбой в течение определённого времени (по умолчанию — 4 секунды). С помощью левой кнопки мыши (ЛКМ) перемещайте зелёную зону на одну ячейку вправо. Если перестать нажимать, зона будет медленно сдвигаться влево.

### Особенности

- У каждой рыбы есть уровень редкости, который отображается в виде звезды. Чем больше звезд, тем реже встречается рыба.
- Рыбы различаются по внешнему виду, а также могут отличаться по размеру и весу.
- Рекомендуется торговать рыбой в торговой зоне.
