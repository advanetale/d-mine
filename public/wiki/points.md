# D.Mine поинты

D.Mine поинты (dp) возможно заработать выполняя ежедневные квесты в игре. Их можно обменять на визуальную косметику по команде /rewards

## Баланс

Для открытия баланса D.Mine поинтов используйте:

```
/points
```

### Особенности

- Квесты обновляются каждый день в 00:00 по МСК
- Задания имеют разные степени сложности
