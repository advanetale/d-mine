# D.Mine поинты

![Торговая зона](/wiki-images/points1.png)

_Ьригадир в лобби_

D.Mine поинты (dp) возможно заработать выполняя ежедневные квесты в игре. Их можно обменять на визуальную косметику у бригадира в лобби.

## Баланс

Для открытия баланса D.Mine поинтов используйте:

```
/points
```

### Особенности

- Квесты обновляются каждый день в 00:00 по МСК
- Задания имеют разные степени сложности
