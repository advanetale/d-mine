# Блок и текст дисплей

![Блок дисплей](/wiki-images/armor.png)

_Пример редактора на стойке для брони_

На нашем сервере есть уникальная возможность создавать предметы, которые можно гибко и визуально настраивать, делая из этого красивую декорацию. Также оно включает в себя создание галографического текста и редактирование стоек для брони.

### Крафт специальной палочки редактирования

![Крафт](/wiki-images/eascraft.png)

### Правила использования

1. Не создавайте лишних item display и text display, если они не нужны.
2. Не используйте уязвимости плагина. Если нашли, сообщите в поддержку.
3. Избегайте слишком больших item display. Их размер должен быть разумным.
4. Запрещается изменять чужие объекты.

За нарушение правил возможна блокировка, вплоть до перманентной.

## Управление

Щелкните правой кнопкой мыши: Выбрать
Щелкните левой кнопкой мыши: Вернуться назад
Щелкните левой кнопкой мыши: Открыть меню
Q: Отмените выбор объекта
Shift: Отключите привязку
F: Переключитесь между режимами локального/глобального/масштабирования
 
## Краткая инструкция

Щелкните правой кнопкой мыши по строке, чтобы использовать инструмент Перемещение. Переместите курсор, перемещаясь или осматриваясь, затем щелкните правой кнопкой мыши, чтобы подтвердить изменения. Вы можете отменить изменения и восстановить предыдущее положение, щелкнув левой кнопкой мыши.
Щелкните правой кнопкой мыши по кругу, чтобы использовать инструмент Поворот. Он работает так же, как инструмент «Перемещение».
Некоторые объекты позволяют переключаться между локальным и глобальным режимами с помощью клавиши F. На локальный режим влияет вращение, например, с его помощью можно перемещать подставку для брони вдоль рычагов. В глобальном режиме используются глобальные координаты.
Используйте /eas undo и /eas redo для отмены/возврата изменений. Вы можете отменить любую операцию, выполненную с помощью EasyArmorStands, а также вручную установить или уничтожить броневые стойки.

У доспехов 7 костей:

- Голова
- Тело
- Левая рука
- Правая рука
- Левая нога
- Правая нога
- Положение

После выбора подставки для брони вам также нужно будет выбрать кость, которую вы хотите отредактировать. Кость «Положение» — это жёлтая точка посередине (под головой), остальные кости — это белые линии.
Вы можете поднять и перенести подставку для брони, выбрав опорную кость, а затем выбрав инструмент Поднять в центре (там, где сходятся линии).
Используйте /eas name для редактирования пользовательского названия стойки для брони. Это часто используется для голограмм.

Отображаемые объекты можно редактировать так же, как и кости доспехов.
Кроме того, их можно масштабировать. Войдите в Масштабирование режим, щёлкнув правой кнопкой мыши, не глядя ни на что, как при переключении между локальным и глобальным режимами.

Чтобы открыть меню, щелкните левой кнопкой мыши, когда не выбрана ни одна кость или инструмент.
