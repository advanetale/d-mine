# Двойной прыжок

![Двойной прыжок](/wiki-images/jumpwall.gif)

_Пример действия двойного прыжка_

Для успешного выполнения двойного прыжка нужно находиться рядом с любой стеной из блоков.

### Особенности

- Вы можете комбинировать прыжки, если стены из блоков находятся рядом.
- Вы можете менять высоту прыжка зажав шифт на несколько секунд.
