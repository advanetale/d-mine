# Профили

Вы можете посмотреть свой профиль, узнать базовую информацию о себе, поставить статус, установить пол или посмотреть профиль любого игрока, а также оценить его, поставив положительную или отрицательную оценку.

```
Использование: /profile <ник игрока>
```
## Особенности

Вы можете установить статус с помощью команды: 
```
/profile status <ваш статус>
```


Также вы можете установить пол своего персонажа:

```
/gender male/female
```
